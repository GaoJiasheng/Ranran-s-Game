# Ranran-s-Game · 冉冉的游戏屋

给冉冉的 iPad 游戏合集（SwiftUI，iPadOS 17+）。主页八个游戏（横屏四列两排，竖屏两列四排），目前收录：

- **五子棋** — 十档难度（小兔 1–3、熊猫 4–6、猫头鹰 7–9、龙宝宝 10），或和家人双人对战。
  按住棋盘瞄准、松手落子；支持悔棋、提示，低档对手会在你快输时提醒你。赢了按「赢下 / 没悔棋 / 没用提示」拿 1–3 颗星。
- **象棋** — 同样的十档难度和四位小伙伴（α-β 搜索的电脑对手，低档会乱走、高档会算杀），可以执红或执黑，也能和家人下。
  点子显示能走的地方，被将军时圈出将军的子；悔棋、提示、三次重复局面 / 长时间不吃子判和。

- **围棋** — 九路棋盘、中国规则（数子，白贴 7.5）。第 1–3 档是「吃子棋」（先吃到 1 / 3 / 5 颗子赢），第 4–10 档是正式对局
  （蒙特卡洛树搜索 + RAVE 的电脑对手）。双方都停一手后自动判断死子、数子，并在棋盘上标出每一点归谁。

- **国际象棋** — 完整规则（王车易位、吃过路兵、升变、逼和、三次重复 / 五十回合 / 子力不足判和，走法计数对照标准 perft）。
  同样的十档对手（1–3 档会随便走、留机会给初学者，高档 α-β 搜索到 8 层），执白或执黑，也能和家人下。
  点或拖棋子走棋，能走的格子有圆点；低档走出会丢子、会被一步杀的棋时先提醒一次。悔棋、提示、棋谱复盘和逐步点评。
- **数独** — 五组 70 关：四宫格·水果（用四种水果代替数字）→ 四宫格·数字 → 六宫格 → 九宫格·入门 → 九宫格·进阶。
  每一关都只有一个解，并且只用这一组教过的办法就解得出来。填错的格子变红、圈出和谁重复，可以改；六宫格起有笔记。
  「提示」是讲道理的：先圈出该看的行 / 列 / 宫并说出理由，再点一次才给答案。星星 = 过关 / 没用提示 / 没填错。
- **七巧板** — 四组 40 个图形：入门（影子里画着每块的线）→ 进阶（要自己转、自己翻）→ 高手 → 大师（只有影子）。
  拖动板子、点一下转 45°、平行四边形可以翻面，靠近正确位置会自动吸附。只要把影子正好盖满就算对，不要求和参考答案一样的摆法。
  星星 = 过关 / 没用提示 / 没偷看（画着线的两组是：过关 / 提示最多一次 / 没用提示）。全部图形见 `docs/tangram-figures.png`。
- **华容道** — 四组 53 关：入门（最少 2–10 步）→ 进阶 → 高手 → 大师（最后有经典的"横刀立马"）。大木块是小兔，要从下面的门出去。
  拖木块沿着空位滑；一块木块朝一个方向滑一次算一步。「提示」由求解器从当前局面算出最好的下一步。
  星星 = 过关 / 没用提示 / 步数不多（界限写在屏幕上）。

**教学**（每个益智游戏首页右上角）：猫头鹰老师一步一步教，每句话都有配音。一开始只开放「基础规则」，学完一组才解锁下一组（解锁过的组以后加了新课也不会再锁上）：
- 五子棋 16 课：基础规则 → 进攻招数（活三、活四、冲四、四三、三三）→ 防守（先看对手、跳三堵中间、边堵边攻、先冲四再防守）→ 开局与实战（四四、连续冲四、练习题）。
- 围棋 34 课：认识围棋（气、提子、禁入点、打劫、谁的地盘大谁赢）→ 吃子技巧（叫吃、双叫吃、抱吃、门吃、征子、枷、倒扑、接不归）→ 连接与对杀 →
  死活（眼、两眼活棋、直三曲三、直四方四刀把五梅花五）→ 布局（九路：金角银边、沿边拆、先占大地方）→ 终局与数子（围地、收官、单官、死子、停一手、数子，最后在七路小棋盘上从第一手下到数子）。
  吃子类的题由战术搜索判断，征子、枷这种步数不固定的课会一直循环到真的吃掉。
- 象棋 26 课：基础规则（棋盘、认识棋子、每个子怎么走、将军和将死）→ 基本杀法（对面笑、马后炮、重炮、卧槽马、挂角马）→
  得子战术（棋子的价值、保护和兑子、捉双、牵制、抽将）→ 开局（三原则、当头炮对屏风马、飞相局、仙人指路、开局别犯的错）→
  残局（单车杀将、双车错、高兵杀将、铁门栓、闷宫）。
- 每道题都由规则引擎判断（只认规则上真正对的答案）；错一次给提示，错两次亮出答案再让她自己做。
  走错的那一步如果有明确的后果（没堵住白棋就连五、叫吃方向错了白棋就逃掉、子走到被吃的地方），先把后果演给她看，再退回来重下。
- **小奖杯**：每一课按"第一次就做对多少题"给金 / 银 / 铜杯，只记最好的一次；课程表和「我的」里都能看到哪几课还不熟。
- **练一练 / 复习**：学过的课可以「练一练」，课程表右上角的「复习」从学过的课里抽 5 题。局面会随机镜像、旋转（象棋左右镜像），记位置没用。
- 学完一组可以直接「去下一盘」（自动选好合适的档位）；五子棋、象棋复盘里的失误旁边有「复习这一课」。
- 国际象棋 30 课：认识棋子 → 将军和将死 → 特殊走法 → 基本杀法 → 得子战术 → 开局和残局。
  数独 18 课：基础规则 → 找唯一 → 排除法 → 九宫格。七巧板 13 课：认识七巧板 → 小块拼大块 → 看图的窍门。
  华容道 13 课：基础 → 让路的办法 → 多想几步。各自的规划在 `docs/tutorial-<游戏>.md`。
- 课程规划见 `docs/tutorials.md`，以后的新游戏都按这个思路先写教学。改了内容要跑 `zsh tools/tutorials/validate.sh`（答案、分支、练习的每种变换、走错的后果、配音清单都要过）。

**全局奖励**（全 App 一套，规矩都在 `Core/Rewards/RewardRules.swift`）：

- **星星**只有一种，主页右上角是总数。每颗星都记在 `<科目>.stars.<哪里拿的>` 上，所以每一科拿了多少随时算得出来。
  | 做什么 | 给几颗 |
  |---|---|
  | 学一课（棋类教学） | 铜杯 1、银杯 2、金杯 3；杯子变好了补差额 |
  | 复习 | 每种棋每天第一次 1 颗 |
  | 赢电脑一盘 | 1~3 颗（赢 + 没悔棋 + 没用提示）。只有在"现在的水平"附近（最高赢过的档往下一档及以上）给全额；更低的档每盘 1 颗、每天前 3 盘有，刷不了 |
  | 第一次赢下新的一档 | 另加 5 颗 |
  | 解谜（数独、七巧板、华容道） | 每一关 1~3 颗，只记最好的一次，变好了补差额，重玩刷不了 |
  | 加减乘除 | 每道题第一次"一遍就答对"1 颗 |
  | 今天的三颗星 | 学一课、算一组题、玩一局（下一盘棋或者解谜过一关），三样都做了另加 3 颗（只记做到了多少天，断了不清零） |
- **星星奖章**：星星攒够了解锁（5、15、30 … 800 颗，共 12 枚）。门槛以后可以调，庆祝过的不会收回。
- **本领奖章**：和星星多少无关，学会一样具体的东西就拿到——学完一组课、打败一位小伙伴、通过一组解谜关卡、通过数学的一章、坚持 3 / 7 / 14 / 30 天。
- **毕业线**：每一科"学会了"的标准。棋类 = 赢下第 N 档就算通过，不要求先上完课（五子棋 4、象棋 3、围棋 4、国际象棋 3）；
  解谜类 = 通过前几组的全部关卡（数独到九宫格·入门，七巧板到高手，华容道到进阶）；加减乘除 = 30 关全部通过。
  主页每张卡片上显示学会了百分之几，奖章墙每一科一页（进度环、每条目标、本领奖章），「我的」里的「学到哪了」给家长看。
- **约好的奖励**：家长在「我的」里长按打开，给星星奖章、毕业奖章各写一句现实里的奖励，孩子拿到时会看到。跟着存档导出导入。
- 升级到这一版时，以前学过的课、赢过的档会补发星星，主页说一次。
- **以后加新游戏**：照 `docs/new-games.md` 来（哪些文件是新游戏自己的、哪些已经接好、做到什么程度算完）。星星记在 `<科目>.stars.…` 上（`store.earnStars` / `recordWin` / `payLessonStars`），在 `Core/Rewards/Subject.swift` 的 `Subjects.all` 里登记一项
  （有课程和十档对手的棋直接用 `Subject.board(...)`），主页、奖章墙、「我的」就都带上它了；它的活动调 `store.noteDaily(...)` 算进今天的三颗星。
  改了规矩跑 `zsh tools/rewards/test.sh`。

- **加减乘除** — 英文数学应用题，照新加坡小学一、二年级的思路出题（冉冉在海外上学，题目、提示、朗读全是英文）。
  十章：Altogether / Part & Whole / How Many More? / More or Fewer?（"Bunny has 3 fewer than Panda" 这类陷阱）/
  Giving / Equal Groups（乘法）/ Sharing（除法）/ Numbers to 100（不进位 → 进位退位，带 dollars、cm、m）/
  Two Steps（先分 (a)(b) 两问，再只问最后一问）/ Challenge（各种题型混合，数到 100）。
  每章三关，前七章 = 新加坡数学的 C-P-A：**Act it out**（亲手拖物品、往盘子里分）→ **Draw a model**（每读一句画一段线段图）→ **Just read**。
  Just read 关先选算式（"28 − 10 = ?" 还是 "28 + 10 = ?"）再算；答错时先针对错法解释，再给帮助（只看文字 → 画线段图 → 用实物演；大数用十和一的小棒）。
  **星星**：每道题第一次"一遍就答对"得 1 颗，同一道题只给一次；关卡下面显示"已得 / 这一关一共有几颗"。Play again 换下一套题。
  **过关**：第一次就答对 75% 才算过关，过了关才开下一关（「我的」里有家长开关可以全部解锁）。每关最后把做错的题再出一遍。
  关卡页上有孩子自己能点的 **Tricky ones**（错题再练）和 **Practice mix**（按她最薄弱的题型从题库里挑 8 道）。
  每关 6 / 8 / 10 题，题目来自预先出好的题库（每关 3 套，共 738 题），故事句、问题、答案句和提示都**预先录好了英文配音**
  （英式女声 Sonia）；拖物品时报实时数量这类随时变化的话用系统语音读。名字按 "Ranran" 录，改了名字的话带名字的句子会用系统语音。

**我的**（点主页左上角头像进入，不占主界面）：
- 自定义名字（最多 8 个字），不需要登录，所有数据只存在这台 iPad 上。
- 棋谱：每盘下完自动保存，可以一步一步**复盘**；电脑逐手**分析**（妙手 / 好棋 / 疑问手 / 失误 / 错过胜机），
  画形势曲线，并在棋盘上标出推荐的下法。棋谱格式是通用的（`GameRecord.game` 区分棋种），以后的棋类可以共用。
- 应用题：按题型统计做对 / 做错多少，以及选算式选对 / 选错多少（区分"不会列式"和"算错"），做错的题收进**错题本**，点一道就能再做一遍。
- 教学小奖杯：三门棋每一课的金 / 银 / 铜杯，还不熟的课单独列出来。
- 存档导入 / 导出：整份存档（名字、星星、进度、棋谱、错题、设置）导出成一个 JSON 文件，换 iPad 时再导入。

## 装到 iPad 上

1. 用数据线把 iPad 连到这台 Mac，iPad 上点「信任此电脑」。
2. iPad 打开 **设置 → 隐私与安全性 → 开发者模式**，打开后重启。
3. 双击打开 `RanranGame.xcodeproj`，顶部设备选成她的 iPad，点 ▶︎ 运行。
4. 签名用的是你的开发者账号（Team `D33974QQTD`），装好后一年内有效。

> 项目放在 iCloud Drive 里，`codesign` 不接受 iCloud 加的文件属性，所以构建产物必须放在 iCloud 之外
> （Xcode 默认的 DerivedData 就可以，别把构建目录设在项目文件夹里）。

# 七巧板教学规划

内容在 `tools/tutorials/build_tangram.py`（生成 `RanranGame/Tutorials/tangram.json`），判题在
`RanranGame/Games/Tangram/Logic/TangramLessonLogic.swift`，测试 `zsh tools/tangram/test.sh`。

## 思路

七巧板难在两件事：**手上**（拖、转、翻要熟练）和**眼睛**（看一整块黑影，想出哪块放哪里）。
所以先练手，再练"一样大可以互相换"这个最关键的形状知识，最后才教看图的窍门。每组学完正好对应一组关卡：

| 组 | 学完去 | 为什么 |
|---|---|---|
| basic 认识七巧板 | 第 1 组「入门」 | 入门的影子画着分界线、前几关板子已经转好，只要会拖、会认形状 |
| combine 小块拼大块 | 第 2 组「进阶」 | 进阶要自己转、翻；知道两个小三角 = 一块中三角/正方形/平行四边形，才不会卡住 |
| tricks 看图的窍门 | 第 3 组「高手」 | 高手的影子没有线，要用"先放大三角、看尖角、看剩下的形状" |

## 题型（都由几何判断，不认死答案）

- `fill`：把托盘里的板子全部放进影子，**正好盖满**。判断 = 每块都在影子里、互不重叠、面积加起来等于影子（`TangramChecker.solved`），
  所以两块大三角互换、别的拼法都算对。影子本身用一种参考拼法写出来（就是托盘里的那几块）。
- `pick:L`（M S Q P）：点一下老师说的那种板子。

放错（露到影子外、压在别的板子上、方向不对）：板子弹回托盘，老师提醒一句（`TangramTutorial.outside / overlap / turnFirst`），**不算做错**——
七巧板本来就要试；同一道题放错三次才算错一次（第一次给提示，第二次亮出答案的虚线，这是 LessonFlow 的规矩）。
放在影子旁边的空地上不算放错。

练一练 / 复习：每段题整个局面随机转 90° 的倍数、左右翻（8 种，`TangramLessonBoard.transformed`），托盘里的朝向一起变，
难度不变但记不住位置。通用说法见 `TangramTutorial.kit.practicePrompts`，都不提方向。

## 第一组 · 认识七巧板（basic）

| 课 | 教什么 | 动手 |
|---|---|---|
| t1 七块板子 | 大三角形 ×2、中三角形、小三角形 ×2、正方形、平行四边形，能拼成大正方形 | 依次点出五种板子 |
| t2 拖一拖 | 按住拖到影子上，对齐会自己吸进去；放错可以再拖 | 一块、一块、两块、三块（板子已经转好） |
| t3 转一转 | 点一下板子转 45°；方向要和影子一样 | 大三角、中三角、小三角（斜放）、正方形（从菱形摆正） |
| t4 翻一翻 | 平行四边形有正反面，按「翻面」；有的要翻、有的只要转 | 翻、翻+转、只转（区分） |
| t5 拼回大正方形 | 两块大三角占一半；大块先放 | 帮放好四块补三块；七块自己拼 |

## 第二组 · 小块拼大块（combine）

| 课 | 教什么 | 动手（影子没有线） |
|---|---|---|
| c1 两个小三角 | 两个小三角 = 正方形 = 中三角 = 平行四边形那么大 | 三种都拼一次 |
| c2 拼大三角形 | 大三角 = 中三角+2小三角 = 正方形+2小三角 = 平行四边形+2小三角 | 三种拼法 |
| c3 两个大三角 | 两块大三角能拼正方形、大三角形、平行四边形（很多图形里都藏着） | 三种 |
| c4 五块小板子 | 七块 = 两块大三角 + 五块小板子（各占一半） | 五块拼三角（有线、无线），七块拼大三角形 |

## 第三组 · 看图的窍门（tricks）

| 课 | 窍门 | 动手（无线的真关卡图形，部分板子先放好） |
|---|---|---|
| k1 先找大三角 | 先想两块最大的放哪里 | 小猫、小鸭子、小房子只缺两块大三角 |
| k2 看尖角 | 尖角只能放三角形的尖角 | 帆船船身、小树、小鱼 |
| k3 剩下的是什么形状 | 看剩下的空位形状，挑一样的板子（可能要翻面） | 大正方形缺正方形+平行四边形；小兔子缺两块；天鹅缺三块 |
| k4 自己拼一个 | 三个窍门一起用 | 小房子、火箭、小猫整只拼 |

## 读音

`tools/voice/extra_tangram.json`：转一转 / 转一下 / 转一点点 → 赚（zhuàn，转动），空着 → 控着（kòng），
另备了长方形 → 常方形、重叠 → 虫叠（课文里目前没有用到"重叠"，提醒说"压在别的板子上"）。课文避开了"得 děi"。
test.sh 会检查这些词出现时有替换。

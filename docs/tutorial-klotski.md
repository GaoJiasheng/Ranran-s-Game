# 华容道教学规划

课文在 `tools/tutorials/build_klotski.py`（生成 `RanranGame/Tutorials/klotski.json`），判题在 `RanranGame/Games/Klotski/Logic/KlotskiLessonLogic.swift`，
命令行测试 `zsh tools/klotski/test.sh` 会把每一道题、每一种练习的样子都解一遍。

## 这个游戏对 6–8 岁的孩子难在哪

1. **要"让路"**：想让小兔走，先得挪开挡路的木块。孩子的第一反应是直接推小兔，推不动就不知道怎么办了。
2. **要想好几步**：挪 A 是为了挪 B，挪 B 是为了给小兔让路。前后三四步以上就要靠"倒着想"。
3. **木块不能转身、不能拐弯、不能跳**：手上拖着木块的时候，会下意识想"绕过去"。
4. **一步怎么算**：本游戏里"一块木块直直地滑过几格，只要路上是空的，都算一步"；先往右再往下是两步。

所以不教"最短的解法"，先教**看清是谁挡路**，再教**让路的几种办法**，最后才是**往前想几步**。每一课都在真木盘上动手，不是听讲。

## 课程表（3 组 13 课，43 道题；每课 4–7 步、至少 2 道题）

| 组 | 课 | 教什么 | 题型 |
|---|---|---|---|
| **基础**（认识木盘，学会滑木块） | 小兔要回家 | 木盘、出口在最下面中间、小兔是最大的一块；竖块、横块、小方块各是什么 | 点一点（按形状、点出口前面的格子） |
| | 滑一滑 | 按住木块拖，松手就停在格子里；横块、竖块都能朝四个方向滑；滑几格都只算一步 | 滑一步、滑到头 |
| | 过不去的路 | 不能跳过别的木块；不能拐弯，要分两步；哪些木块现在动不了 | 滑到头（被挡住）、两步走到圈出来的格子、点"动不了 / 能动"的木块 |
| | 挡路的先挪开 | 小兔下面有一块木块：先点出挡路的，再挪开，再走小兔（先 1 步、再 3 步） | 点挡路的、把路空出来、1 步 / 3 步让小兔出门 |
| | 走错了怎么办 | 撤销一步、回到开头；有了这两个按钮，放心试 | 先滑再撤销、3 步出门 |
| **让路的办法** | 先看谁挡路 | 每次先看小兔正下面是谁；挡路的可能不止一块 | 点挡路的（1 块 / 2 块）、2 步 / 3 步出门 |
| | 腾出两个空位 | 小兔是大块，要两个并排的空位；两块小方块一边一块让开；小兔自己也可以让一让 | 空出圈出来的两格、3 步 / 4 步出门 |
| | 小方块最灵活 | 满盘时先看哪些能动（只有小方块）；小方块先走，大块才有地方 | 点能动的（横刀立马的开局）、小方块钻到空位、3 步出门 |
| | 把空位送过去 | 木块一动空位就换了地方；想要空位在哪里，就把那里的木块挪走 | 把四个格子空出来、5 步出门、让小兔走到圈出来的格子 |
| **多想几步** | 倒着想 | 先想小兔最后在哪里（出口前面要空着），再往回想 | 点"小兔到出口会盖住哪些格子"、5 步 / 4 步出门 |
| | 竖块和横块 | 竖块不会躺下、横块不会站起来；想换位置要一块一块让路 | 让竖块 / 横块走到圈出来的格子（要先让开别的） |
| | 不走回头路 | 一块木块滑过去又滑回来，白走两步；每一步都要有用 | 4 步、5 步、5 步出门 |
| | 小兔回家 | 把前面的办法合起来用 | 4、5、6 步出门，学完去闯关 |

学完每一组，直接去对应的一组关卡：基础 → 入门，让路的办法 → 进阶，多想几步 → 高手（`playLevels`）。
这样每组课和同样难度的关卡是对上的：入门关卡（2–10 步）用到的就是前两组学的"看谁挡路、先挪开"。

## 为什么这样排

- **先点后滑**：第一课只让她认识木块的名字和出口，不要求手上的动作；第二课才开始拖。
- **一次只加一个新想法**：看谁挡路 → 挪开 → 腾两个空位 → 小方块先动 → 把空位送过去 → 倒着想。每个想法都有"点一点"的题（先学会看）和"动手"的题（再学会做）。
- **步数从 1 步到 6 步**：每一道"N 步让小兔出门"的题，N 都是求解器算出来的最少步数，课文里写的就是这个数（测试会核对）。
  多想几步这一组用的盘面都在 4–6 步之间，和关卡的"入门 → 进阶"衔接。
- **题目判的是目标，不是某一步**：`empty:` / `at:` / `bunnyAt:` / `free:N` 都是看局面（路空出来没有、小兔到出口没有），
  她用任何办法做到都对；只有"滑一格往下"这类教动作的题才要求具体的一步，而且动了别的木块只提醒、不算错。
- **错了怎么办**：滑错或者步数用完，木块自动退回这道题开始的样子（不用她自己撤销），第一次说提示，第二次把答案亮出来（发光 + 箭头，
  点一点的题让对的木块发光）再让她自己做一遍。

## 练一练 / 复习

- 每一道题都写了 `drill`（不提左右、上下、横竖、字母），练习时代替课文。
- 同一道题有两种样子：原样、**左右镜像**（出口在正中间，镜像永远成立）。盘面、箭头、圈、规则里的格子和方向一起变，
  所以她不能靠"点哪个位置"来记答案。测试会把每一段 × 每一种样子都解一遍。
- 没有写 `drill` 的题按规则种类有通用说法（`KlotskiTutorial.kit.practicePrompts`），课文里每道题都写了 drill，这些是兜底。

## 配音

- 课文每一句都自动进配音清单；游戏里还要说的两句固定台词写在 `KlotskiLines`，同样抄进 `tools/voice/extra_klotski.json`：
  「这一步要动发光的那块木块。」「先滑一块木块，再点撤销。」
- 读音：这门课里的"空"都读 kòng（空位、空格、空出来、空着）→ 配音时换成"控"；"倒着想"的"倒"读 dào → 换成"到着"。
  课文里避开了容易读错的"重来"（用"回到开头"）、"得 děi"、"一行"（用"一排"）、"着急"等；测试里有一张黑名单。
- 数字只用中文数字（"三步"），不用阿拉伯数字，TTS 读起来最稳。

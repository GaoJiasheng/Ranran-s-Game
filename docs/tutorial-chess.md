# 国际象棋教学规划

棋盘 8×8，冉冉执白，白方在下面。教学棋盘就是正式棋盘；认识棋子的那几课只摆这一课要用的子（可以没有王），
别的课都摆两个王。课的 id（c1…c30）是进度存档的钥匙，不能改、不能复用；顺序可以调。

内容写在 `tools/tutorials/build_chess.py` 里，生成 `RanranGame/Tutorials/chess.json`。改完跑 `zsh tools/chess/test.sh`（`-v` 看每一步的答案）。

## 为什么这样排

象棋教学是五组（基础 → 杀法 → 战术 → 开局 → 残局）。国际象棋多了三条特别的规则（易位、升变、过路兵），
棋子又比象棋少一种，所以排成六组，每组 3–7 课，学完一组就能解锁、马上去下一盘：

1. **认识棋子**：一课一个子。先学车和象（直线、斜线最好懂），后是"车 + 象"，再学只走一格的王，最后是最特别的马和兵。
   学完就能和第 1 档（小兔，大多数时候乱走）下棋了。
2. **将军和将死**：吃子 → 将军 → 解将的三种办法 → 将死 → 逼和。逼和放在这一组的最后，因为孩子学会将死以后，
   第一次和弱的电脑下，最常见的"赢不了"就是把对方逼和了。
3. **特殊走法**：王车易位（开局三原则要用）、兵升变（残局要用）、吃过路兵（最少见，放最后）。
   这三条不学也能下，所以放在将死后面，免得一开始规则太多。
4. **基本杀法**：底线杀（最常见，也教她自己的王要留出口）、双车错、后和王配合、闷杀。都是"一步或两步就将死"的局面。
   学完去第 3 档（毕业线就是赢下第 3 档）。
5. **得子战术**：先讲子力（兵 1、马象 3、车 5、后 9），再讲保护和交换，然后是捉双、牵制、串击、闪击。
   每一招都是"走一步 → 黑方应 → 吃到子"两道题，黑方怎么应都吃得到。
6. **开局和残局**：开局三原则（占中心、出马出象、早易位）和开局别犯的错（别太早出后、抓住四步杀），
   残局三课：王后杀单王、王车杀单王、送兵升变——快赢了却收不了尾最可惜。

## 判题规则（`Chess/Logic/ChessLessonLogic.swift`，全部由引擎算）

| 规则 | 意思 |
|---|---|
| `any` | 随便走（配合 `piece`：认识走法） |
| `capture` | 吃掉一个子 |
| `check` | 将军 |
| `mate` | 一步将死 |
| `mateIn:N` | 黑方怎么应都没用，N 步之内（算这一步）将死；逼和不算 |
| `escape[:king\|block\|capture]` | 被将军了：走开 / 挡住 / 吃掉将军的子 |
| `bestCapture` | 能吃的子里，吃完得失最好的那些 |
| `safe` | 走完以后走过去的子不被攻击 |
| `hold` / `gain:N` | 黑方先应一步，双方再把能吃的吃完，白方不亏 / 至少净赚 N 分 |
| `castle[:k\|q]` | 王车易位（短 / 长） |
| `promote[:q\|r\|b\|n]` | 兵升变（升成指定的子） |
| `promoteIn:N` | N 步之内一定能把兵安全地升成后 |
| `enpassant` | 吃过路兵 |
| `develop[:q]` | 开局把原位的马、象放到第三排以外，不白送，马不跳到边上（`:q` 同时攻击黑后） |
| `center` | 开局用兵占 d4、e4、d5、e5 |

`task.accept` 也可以直接列答案（格子或着法）。多步题（`reply: engine`）由测试把白方每一种被判对的走法 × 黑方每一种应着都走一遍，
后面的题必须都有解，而且后面还有题时不能已经把棋下完。走错时能说清楚后果的（被吃、黑王逃走、逼和），先演示再退回。

## 各课

### 第一组 · 认识棋子（basic，学完去第 1 档）
| 课 | 内容 | 动手 |
|---|---|---|
| c1 棋盘和棋子 | 64 格，深浅相间；白下黑上、白先走；六种棋子 | 点白王、黑后、白车、白马 |
| c2 车 | 直线、走多远都行；被挡住要停；走到对方的子上就是吃 | 车走到发光格；吃黑兵；挑一个吃得到的 |
| c3 象 | 斜线；永远走同一种颜色的格子 | 象走到发光格；吃子；绕开被挡住的斜线 |
| c4 后 | 车 + 象 | 走到角上；两个都能吃；只有一个吃得到 |
| c5 王 | 一次一格；不能走到会被吃的地方 | 走到发光格；吃没有保护的兵（有保护的那个走不了） |
| c6 马 | 日字；能跳过别的子 | 走到发光格；从兵堆里跳出来吃子；找吃得到的 |
| c7 兵 | 往前一格、第一步可以两格；斜着吃；前面挡住就走不动 | 走两格；斜吃马；挑能吃的那个 |

### 第二组 · 将军和将死（rules，学完去第 2 档）
| 课 | 内容 | 动手 |
|---|---|---|
| c8 吃子 | 走到对方的子上就吃掉；自己的子不能吃 | 马、象、兵各吃一个 |
| c9 将军 | 下一步能吃到王就是将军 | 车、马、象各将一军 |
| c10 被将军了怎么办 | 走开、挡住、吃掉 | 三种办法各一次，再自己选 |
| c11 将死 | 解不了的将军；将死就赢 | 底线车杀；后王杀；车王杀 |
| c12 逼和不是赢 | 没被将军却无路可走 = 和棋 | 两道"将死，别逼和"（走成逼和会演示） |

### 第三组 · 特殊走法（special，学完去第 2 档）
| 课 | 内容 | 动手 |
|---|---|---|
| c13 王车易位 | 王走两格、车跳到另一边；三个条件 | 短易位；一边被挡住时长易位；王要经过被攻击的格子时换一边 |
| c14 兵升变 | 走到底变成后 / 车 / 象 / 马 | 升后；吃子升变；升变将死 |
| c15 吃过路兵 | 对方兵一下走两格停在旁边，下一步可以吃 | 吃过路兵；走一步看黑兵冲两格，再马上吃 |

### 第四组 · 基本杀法（mates，学完去第 3 档）
| 课 | 内容 | 动手 |
|---|---|---|
| c16 底线杀 | 王被自己的兵堵住 | 一步底线杀；双车冲底线（两步） |
| c17 双车错 | 两车轮流将军，一排一排赶 | 两步一道；三步一道（电脑应） |
| c18 后和王配合 | 后贴着王将军，自己的王保护 | 两道一步杀；一道两步杀（别逼和） |
| c19 闷杀 | 王被自己的子围住，马将军 | 一步闷杀；送后再闷杀（两步） |

### 第五组 · 得子战术（tactics，学完去第 4 档）
| 课 | 内容 | 动手 |
|---|---|---|
| c20 棋子的价值 | 兵 1、马象 3、车 5、后 9 | 选划算的子吃；被攻击的马走到安全格 |
| c21 保护和交换 | 有保护 = 能吃回来；用小换大 | 保护被捉的象；马换车；用兵去吃有保护的马 |
| c22 捉双 | 一步攻击两个子 | 马将军捉车再吃车；后将军捉车再吃车 |
| c23 牵制 | 挡在王前面的子不能动 | 点出被牵制的子；兵捉死被牵制的马 |
| c24 串击 | 将军，王躲开，吃后面的子 | 车串击；象串击 |
| c25 闪击 | 前面的子走开，后面的子攻击 | 马跳开吃后带闪将；象将军，后吃后 |

### 第六组 · 开局和残局（endgame，学完去第 5 档）
| 课 | 内容 | 动手 |
|---|---|---|
| c26 开局三原则 | 占中心、出马出象、早易位 | 从开局走 e4、出马、出象、短易位（黑方照谱应） |
| c27 开局别犯的错 | 别太早出后；看好 f7 | 出马赶后；被赶的后走到安全格；抓住四步杀 |
| c28 王后杀单王 | 后关住、王靠近、别逼和 | 一步杀；两步杀（电脑应） |
| c29 王车杀单王 | 两个王面对面，车底线将 | 一步杀；先走王再杀 |
| c30 送兵升变 | 王追不上就冲；王在旁边保护兵 | 兵连冲三步升后；王保护下升后 |

## 练一练 / 复习

能单独拿出来的题按规则配了通用说法（`ChessTutorial.practicePrompts`），没有规则的写了 `drill`，都不提方向和格子名字。
练习时局面会随机左右镜像（`ChessLessonLogic.transform`）；局面里有易位权或过路兵时不镜像（王和后不对称，镜像以后就不是合法的开局了）。
只能动某一个子的题，那个子会一直发光。

## 读音

台词里的多音字都过了一遍（测试里有一张检查表）：车（棋子）读 jū，换成「居」；闷杀换成「焖杀」；露出来换成「漏出来」。
将军、将死的「将」读 jiāng，是语音的默认读法；国际象棋没有「将」这个棋子。能换说法的多音字直接换掉了（比如不说「空格」「一行」）。
